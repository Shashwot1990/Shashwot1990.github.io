Python Environment Setup Documentation

1. Creating a Python Virtual Environment Using venv

venv is a built-in module in Python 3.3 and later, which allows you to create virtual environments. Here’s how to use it:

Step 1: Install Python

Download and install Python from python.org. Verify the installation:

python --version

Step 2: Create a Virtual Environment

Navigate to your project directory and run:

python -m venv <env_name>

Example:

python -m venv myenv

Step 3: Activate the Virtual Environment

For Windows:

.\myenv\Scripts\activate

For macOS/Linux:

source myenv/bin/activate

Step 4: Install Packages

With the environment activated, install packages using pip:

pip install <package_name>

Step 5: Deactivate the Environment

To deactivate the virtual environment:

deactivate

2. Creating a Python Environment Using conda

Step 1: Install Conda

Download and install Anaconda or Miniconda. Verify installation:

conda --version

Step 2: Create a New Conda Environment

Run the following to create a conda environment:

conda create --name <env_name> python=<version>

Example:

conda create --name myenv python=3.9

Step 3: Activate the Conda Environment

conda activate <env_name>

Step 4: Install Packages

Use conda install to install packages:

conda install numpy

Step 5: Deactivate the Conda Environment

conda deactivate

Step 6: List Conda Environments

conda info --envs

Step 7: Remove a Conda Environment

conda remove --name <env_name> --all

Key Differences Between venv and conda

Feature venv conda
Python Version Uses system-wide Python version Can specify any Python version
Package Manager Uses pip Uses conda, but can use pip too
Environment Size Lightweight Larger, manages dependencies
Cross-language Support No Yes (supports R, Java, etc.)
Dependency Management Manual Automatic conflict resolution
