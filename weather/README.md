# Leaflet Weather Map

This interactive map displays real-time radar and weather alerts across the United States using open data services from the National Weather Service and Iowa State Mesonet.

🔗 **[View Live Map](https://physic1990.github.io/weather/index.html)**
**[New Live Map](https://physic1990.github.io/photomap/)**

- Live radar from NEXRAD WMS
- Alerts styled by severity (Extreme = purple, Severe = red, Minor = yellow)
- Clickable popups for weather headlines
- Custom basemap with full responsiveness

Data Sources:
- NWS Weather Alerts API
- NEXRAD Base Reflectivity from Iowa State Mesonet
